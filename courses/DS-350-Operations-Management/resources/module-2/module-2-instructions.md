## Module learning objectives

After completing Module 2, students should be able to:

1. List and briefly explain the elements of the control process.
2. Explain how different control charts are used to monitor a process.
3. Learn to use Xbar, R, P, and C charts and interpret the results.
4. Explain the importance of capacity planning.
5. Describe ways of defining and measuring capacity.
6. Briefly describe approaches that are useful for evaluating capacity alternatives.

## Course learning objectives supported

1. Define the different terms in Operations Management.
2. Distinguish between conceptual frameworks and decision-making quantitative models.
3. Describe the assumptions, inputs, and outputs of the different quantitative models.
4. Demonstrate the need to focus on the process, regardless if it is a product or service.
5. Solve problems using the right decision making model and interpret the results.
