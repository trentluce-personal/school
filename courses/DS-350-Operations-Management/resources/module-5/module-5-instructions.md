## Module learning objectives

After completing Module 5, students should be able to:

1. Outline the steps in the forecasting process.
2. Describe qualitative vs. quantitative forecasting techniques.
3. Prepare forecasts with naive, moving average (MA), weighted MA, and exponential smoothing.
4. Calculate forecast error measures including bias, MAD, MSE, and control charts.
5. Prepare a forecast using linear regression for time series that have a significant trend.
6. Interpret Excel linear regression output using the Data Analysis add-in.
7. Expand their knowledge of current topics in operations management and supply chain.
